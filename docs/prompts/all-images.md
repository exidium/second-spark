# Image prompts for Nano Banana 2 (ChatGPT)

One prompt per image, 150 in all, in the order worth generating them. Each prompt is complete: subject, style, shape and what to avoid, because Nano Banana 2 has no separate negative field. Save each result under the **file name** given, drop it into `art/` (web size, under 100KB if you can) and the original into `art/source/`.

## Before you start

1. Generate the four style tests in `ART_STYLE.md` first, or simply the first location (Cemetery). When one looks right, keep that image in the chat and say "same style as this image" at the top of every later prompt. That is the only reliable way to keep 150 images looking like one set.
2. Cadavers use a darker, unflinching variant of the style. Their prompts carry it already; keep a cadaver reference image for that set.
3. Faces must read as real people, never caricatures. No text, frames or borders in any image.
4. Ratios: locations 16:9, cadavers and scoundrels 2:3 portrait with the lower fifth kept dark and plain (the card numbers sit there), everything else 4:3.
